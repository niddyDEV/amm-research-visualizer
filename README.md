# Hybrid AMM Visualizer for RWA Tokens

Проект посвящён моделированию и визуализации гибридного Automated Market Maker (AMM) для токенизированных реальных активов (RWA), где объединяются три подхода: Curve-подобный инвариант, Uniswap V3-подобная концентрированная ликвидность и ценовой оракул.
## Обзор проекта

Основная идея проекта — исследовать, можно ли улучшить стабильность ценообразования и уменьшить проскальзывание в пуле ликвидности за счёт гибридной модели, которая адаптивно комбинирует несколько механизмов AMM.

В текущей реализации проект:
- рассчитывает Curve-подобную кривую ликвидности с параметром усиления `A` и численным решением уравнения для баланса `y`.
- моделирует Uniswap V3-подобную ликвидность внутри ценового диапазона `P_oracle ± delta`.
- строит гибридную кривую на основе статических или динамических весов `alpha`, `beta`, `gamma`.
- оценивает ценовую функцию через численную производную `dy/dx`, что соответствует стандартной аппроксимации конечными разностями.
- визуализирует балансовые кривые, функцию цены, проскальзывание и влияние параметров модели.

## Гипотеза исследования

Гипотеза проекта формулируется следующим образом:

> Если объединить Curve-подобный инвариант, Uniswap V3-подобную концентрированную ликвидность и ценовой оракул в единой гибридной модели с динамическими весами, то можно снизить проскальзывание и уменьшить отклонение цены от оракульной по сравнению с использованием каждого механизма по отдельности при сопоставимых параметрах ликвидности.

Эта гипотеза является проверяемой, потому что в рамках модели можно сравнить кривые цены, диапазоны устойчивости и величину проскальзывания для разных сценариев торговли и разных наборов параметров.

## Цель и задачи

### Цель

Разработать и исследовать модель гибридного AMM для RWA-токенов, которая сочетает преимущества Curve, Uniswap V3 и внешнего ценового оракула для повышения устойчивости цены и снижения проскальзывания.

### Задачи

- Реализовать Curve-подобную модель ликвидности с параметром усиления `A`.
- Реализовать Uniswap V3-подобную модель концентрированной ликвидности в ограниченном диапазоне цен.
- Построить гибридную модель с фиксированными и динамическими весами.
- Сравнить ценовые функции разных AMM-подходов
- Оценить проскальзывание при различных объёмах торговли.
- Исследовать влияние параметров `A` и `delta` на поведение гибридной модели.

## Архитектура модели

### 1. Curve-компонент

Curve-подобная часть отвечает за плавное ценообразование вблизи точки равновесия. Параметр amplification `A` делает кривую менее крутой около целевой цены, что потенциально уменьшает проскальзывание при небольших сделках.

### 2. Uniswap V3-компонент

Компонент концентрированной ликвидности ограничивает активную работу пула диапазоном цен вокруг `P_oracle`. Это позволяет сосредоточить ликвидность в целевой зоне и повысить эффективность капитала.

### 3. Oracle-компонент

Линейная зависимость `y = P_oracle * x` используется как внешний ценовой ориентир. Она задаёт референсную траекторию, относительно которой оценивается отклонение модели и рассчитываются динамические веса гибридного подхода.

### 4. Hybrid-компонент

Гибридная модель комбинирует значения Curve, Uniswap V3 и Oracle. В статическом режиме используются постоянные веса `alpha`, `beta`, `gamma`, а в динамическом режиме веса изменяются в зависимости от отклонения цены Curve от цены оракула.

## Основные параметры

| Параметр | Описание |
|---|---|
| `A` | Параметр усиления Curve-компоненты, влияющий на форму кривой и чувствительность цены. |
| `L` | Общая ликвидность пула. |
| `P_oracle` | Опорная цена оракула для RWA-актива. |
| `delta` | Ширина допустимого ценового диапазона вокруг `P_oracle`. |
| `alpha`, `beta`, `gamma` | Веса Curve, Uniswap V3 и Oracle в гибридной модели. |
| `x_min`, `x_max`, `x_points` | Диапазон и детализация визуализации по оси `x`. |

## Визуализации

Проект поддерживает несколько режимов анализа:
- Основной график балансовых кривых для Curve, Uniswap V3, гибридной модели и линии оракула.
- График ценовой функции, вычисленной через конечные разности.
- График проскальзывания относительно цены оракула.
- График динамических весов гибридной модели.
- Отдельный анализ влияния объёма торговли на цену и проскальзывание.
- Опциональная 3D-поверхность чувствительности проскальзывания к параметрам `A` и `delta`.

## Ожидаемые результаты

В рамках экспериментов ожидается, что гибридная модель будет лучше удерживать цену вблизи `P_oracle` и демонстрировать более стабильное поведение по сравнению с отдельными базовыми механизмами в ряде сценариев.

Подтверждение или опровержение гипотезы должно основываться на сравнении:
- формы кривых ликвидности,
- функции цены,
- уровня проскальзывания,
- устойчивости модели при изменении параметров `A`, `delta` и размеров сделки.

## Ограничения модели

Текущая реализация является исследовательской и визуализационной моделью. Она не учитывает комиссии, арбитражную динамику, задержки оракула, поведение реальных участников рынка и полноформатные on-chain ограничения, поэтому результаты следует интерпретировать как концептуальный анализ, а не как готовую производственную реализацию.

## Практическая ценность

Проект может использоваться как исследовательский прототип для изучения AMM-механизмов для RWA-рынков, а также как учебный инструмент для демонстрации влияния параметров ликвидности, диапазона цен и оракульной привязки на ценообразование в децентрализованных пулах.
